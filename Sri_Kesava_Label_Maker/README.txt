SRI KESAVA FERTILIZERS — LABEL MAKER
=====================================

This is a simple local browser application. It does not require Node.js, Excel, a database, or an internet connection.

HOW TO USE
1. Extract the ZIP file.
2. Open index.html in Google Chrome or Microsoft Edge.
3. Enter the product details on the left.
4. The black-and-white sticker preview updates automatically on the right.
5. Set the exact sticker width and height in centimetres.
6. Click "Print / Save PDF".
7. In the print dialog, select your label printer or "Save as PDF".
8. Set scale to 100% / Actual size and disable browser headers and footers.

IMPORTANT
- The default size is 9 cm × 5.5 cm and is only a starting point. Measure your actual sticker before printing.
- Print a test label first to verify margins, font size, and printer alignment.
- Use only accurate product information and verify the current legal labelling requirements for each fertilizer/product category before commercial use.
- This starter app keeps all data in the page while it is open; it does not save a product database or user accounts.
